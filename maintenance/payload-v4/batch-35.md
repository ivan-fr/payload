## Validation

- Before the fixes, integration tests reproduced the virtual-hook value failure, required immutable restore failure and erroneous JSON schema fetch. The existing missing-relationship restore control already passed and was **not counted as another fix**. Separately restoring the original retry and Stripe implementations produced 11 failing assertions in the new focused option tests, with four default-behavior controls passing.
- Complete unit project: **4,731 passed, 4 skipped across 534 passing files and one skipped file**. Command: `PAYLOAD_TELEMETRY_DEBUG=1 NEXT_TELEMETRY_DISABLED=1 DO_NOT_TRACK=1 pnpm exec vitest run --project unit --testTimeout 30000`.
- Integration fixture `test/server-regressions-batch35/int.spec.ts`: **8 cases** on numeric SQLite, UUID SQLite and the PostgreSQL adapter using a custom schema through PGlite's PostgreSQL socket server. PGlite is not a native PostgreSQL service.
- Core, ecommerce and UI declaration builds passed. The actual backfill documentation function was temporarily included in the core TypeScript project and checked there, then removed from source. Fixture types were generated by the repository generator.
- Targeted lint and formatting checks passed. Local official SonarJS cognitive-complexity (limit 15), nested-conditional and nested-template rules pass for the new projection helper, shared backoff implementation and Stripe adapter factory. This is a scoped local check, not a SonarCloud quality gate. No CI workflow, committed timeout, retry policy or existing test was weakened.

The backfill is an example for a controlled migration after applying the draft schema, with writes paused. It explicitly rejects localized-status collections, requires the operator to choose publication status, runs normal update hooks and has an opt-in context marker for application hooks. It was executed only against disposable test databases, not application data.

The Stripe tests use mocked HTTP responses through the actual SDK fetch transport; no real charge or live Stripe checkout is claimed. Pricing must come from trusted server data, and custom prices must be positive safe integers. The callback does not implement tax calculation, shipping-rate validation or inventory reservation. Retry jitter is opt-in and does not change fixed delays.

No native MongoDB, native PostgreSQL, D1, full Admin browser/assistive-technology workflow or SonarCloud run is claimed. Hook-dependent virtual reads may fetch additional server-side fields to execute the hook; unrelated virtual projections are suppressed and access restrictions remain enforced. Restore deliberately preserves access-denied current values rather than bypassing field access to restore older values.
