## Reproduction and validation

Before fixing, the five focused unit files had **7 failures and 10 passing controls**. All **five integration cases failed** against the original source: global override propagation, persisted duplicate locales, GraphQL permissions and the two CSV output modes. The baseline tests were run with the implementation files restored from the merged main commit, then all fixes were restored. A later partial-tab/query-constraint control additionally demonstrated and covered nested permission handling.

Final checks:

- **2,276 unit tests passed across 225 files**, with two pre-existing skips. This covers core, GraphQL, Drizzle, PostgreSQL/MongoDB/SQLite adapters, import/export, ecommerce, MCP and the previously covered storage packages.
- **5 SQLite integration tests passed**, including actual GraphQL HTTP requests, CSV preview, streamed and in-memory export, access-denial/filter controls, and persisted duplicated/global data. Each test uses the shared Payload fixture lifecycle; temporary schema-generator files are removed in finally blocks.
- TypeScript project builds for GraphQL, PostgreSQL and import/export pass, including their project references.
- The integration TypeScript project includes pre-existing cross-adapter/workspace diagnostics; no diagnostics refer to the new fixture files after correction.
- Package/tool lint, repository formatting and all 24 CI helper checks pass.

The local PostgreSQL test here validates emitted schema metadata, not execution of generated DDL against a live server. Live MongoDB, PostgreSQL and the other database adapters remain subject to the full required GitHub Actions matrix on this PR. No required workflow or quality-gate threshold has been changed. No UI components, focus, keyboard or ARIA behavior have been modified.

The inventory remains a historical 565-issue snapshot: **35 scoped fixes and 530 unassessed reports**, plus post-snapshot issue #19292, for **36 fixes total**.
