## Accessibility scope

Assessment compares with the batch-31 base above. The affected journeys are error feedback for bulk edits/reordering, field rendering and initial disclosure state.

- WCAG 3.3.1 A and 3.3.3 AA: tests verify that public failure reasons reach the feedback boundary once. WCAG 4.1.3 AA: existing toast infrastructure is reused; actual live-region delivery and announcements are not established by mocked-toast assertions.
- WCAG 3.2.2 A and 3.3.4 AA: partial bulk success is distinguished from total failure and triggers the existing list refresh/close callback. This does not establish a complete consequential-operation confirmation or recovery workflow.
- WCAG 1.3.1 A, 2.1.1 A, 2.4.3 A, 2.4.7 AA, 2.4.11 AA and 4.1.2 A were considered for disclosure state, field descriptions, sorting and modal focus. Component contracts establish initialization/preference policy and callback results; rendered names, disclosure keyboard operation, focus restoration after partial success and drag alternatives remain full-Admin checks.
- There are no style changes or palette overrides. Rendered contrast, narrow layouts, visual review and screen-reader speech remain unverified. No product-level conformance is claimed.
