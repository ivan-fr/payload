## Scope and limits

Hierarchy's new optional hook argument is supplied by `find`/`findByID`. Other hook call sites retain their existing document-status fallback. Single-locale ancestor selection and shared-request draft/published cache separation are covered; the older locale-all ancestor fallback strategy is unchanged. This does not claim to resolve the broader operation-argument request #16180.

JSON reference relocation covers root-relative JSON pointers (`#` and `#/...`). External references are left alone, as are nested schemas declaring their own resource IDs. It is not a general external-schema bundler or anchor resolver. Validation continues using the original configured schema, including its declared JSON Schema draft.

The Compose change targets the template's recognizable `payload` + `mongo` stack in `docker-compose.yml`; existing active Postgres and custom database service configurations are retained. Existing volumes are not deleted. Passwordless selected URIs retain local development passwordless behavior; generated database ports bind to loopback. Remote database URLs retain their hostname.

Selected-locale duplication, empty polymorphic ID lists, custom numeric array-ID defaults, nested JSON arrays and SQL localized-status filtering already passed on the batch base and were excluded from the six-report count.

Native MongoDB/PostgreSQL, Docker startup, complete Next/TanStack production builds, browser/screen-reader checks and hosted CI/SonarCloud are not claimed.
