## Reproduction

Against the unchanged base production sources, the six focused unit specs produced **13 failing checks and 29 passing controls**. The actual component/hook tests stub their provider/transport boundaries and render the production implementation; they do not claim a full Admin browser session.

The final integration fixture was also run with only the four original production traversal/upload modules temporarily restored. **All four persistence tests failed**: upload population/access, block subfield hooks, missing required block data, and stored video MIME metadata. The fixed sources were restored immediately afterward. No expected assertion, access callback, validation or CI policy was removed to obtain passing results.
