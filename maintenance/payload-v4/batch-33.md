## Accessibility scope

Assessment compares with the batch-32 base above. The main visible change is suppressing redundant selection events; URL/fallback changes affect state and requests without changing labels, markup or styles.

- WCAG 2.1.1 A and 4.1.2 A: the actual combobox is named Status, opens/closes with the keyboard and still reports a changed option. The test observes `aria-expanded`, callback values and focus after reselecting the current option.
- WCAG 2.4.3 A: the keyboard test verifies focus remains on the combobox. It does not establish complete page tab order or focus restoration after a real bulk-edit drawer closes. Mocked drawer callbacks establish URL preservation and close intent only.
- WCAG 3.2.2 A: identical option values no longer trigger application change callbacks; real changes and clears retain their callback behavior. Bulk refresh preserves the active list URL, including filters.
- WCAG 1.3.1 A, 2.4.6 AA and 4.1.3 AA were considered for labels, displayed selection and feedback. No new roles or live regions were introduced. Screen-reader speech, full Admin announcements, visual focus quality, mobile layouts, contrast modes and product conformance remain unverified.
