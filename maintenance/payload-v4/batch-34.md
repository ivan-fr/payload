## Validation

- With all six production changes temporarily replaced by the base revision, the new tests reproduced **six distinct failures**, one per report. The unchanged unknown-locale control passed. The production changes were then restored.
- Full unit project after the required local package builds: **4,714 passed, 4 skipped; 530 passing files and one skipped file**. Command: `PAYLOAD_TELEMETRY_DEBUG=1 NEXT_TELEMETRY_DISABLED=1 DO_NOT_TRACK=1 pnpm exec vitest run --project unit --testTimeout 30000`.
- Integration fixture `test/server-regressions-batch34/int.spec.ts`: **7 passed on SQLite with numeric IDs**, **7 passed on SQLite with UUIDs**, and **7 passed using the PostgreSQL adapter with a custom schema through PGlite's PostgreSQL socket server**. The shared integration fixture owns database state. PGlite is not a native PostgreSQL service.
- Declaration builds passed for translations, core, Drizzle, MongoDB and import/export: `pnpm exec tsc -b packages/translations packages/payload packages/drizzle packages/db-mongodb packages/plugin-import-export --emitDeclarationOnly`. Fixture types were generated with the repository's type generator.
- Targeted Oxlint passed with no errors (existing explicit-`any` warnings in the shared block-query source remain). Oxfmt and whitespace checks passed. No CI gate, workflow, retry or committed timeout was changed.
- The first full unit run found missing generated CLI, TypeScript-plugin and application-template files in the fresh checkout. Building those artifacts made all affected tests pass, followed by the successful full run above. No test was skipped or weakened to avoid these failures.

CSV downloads now buffer their selected rows, matching saved CSV exports. Memory use therefore grows with export size; the import/export documentation explains this and recommends configuring export limits. Hooks execute once rather than being rerun in a discovery pass. JSON downloads continue to stream.

The version change resolves equal-timestamp flag ambiguity with deterministic ordering. Parallel direct adapter calls are tested; this does not establish serializable behavior for arbitrary overlapping transactions, prove every scheduled-job interleaving, repair existing duplicate flags, or establish that random UUID order is wall-clock order. No native MongoDB, native PostgreSQL, D1, full scheduler race reproduction, full Admin browser/AT workflow or SonarCloud gate is claimed. The Mongo implementation is type-checked and covered by the shared fixture when run against MongoDB in CI.
