## Accessibility assessment

Compared with the batch-30 base above, the affected journeys are preview continuity during autosave, tenant selection during authentication and refresh, localized group identification and link-style actions.

- WCAG 1.3.1 A, 2.4.6 AA and 4.1.2 A: group headings expose the existing locale text through the real label component. Provider tests observe selection state, but do not establish a rendered selector's accessible name/value.
- WCAG 1.4.1 A: link actions have an underline independently of color. WCAG 1.4.3 AA: enhanced-mode text contrast is measured for the tested enabled, selected and hover states in both themes; disabled text is exempt. Ordinary-mode color integration is tested without claiming ordinary-mode contrast conformance or overriding the shared palette.
- WCAG 2.1.1 A, 2.4.3 A, 2.4.7 AA and 2.4.11 AA: native isolated button contracts verify tab order, disabled-control skipping, focus outline and visibility. Full Admin focus order, focus restoration, mobile reflow (1.4.10 AA), text spacing (1.4.12 AA) and target geometry (2.5.8 AA) remain integration/visual checks.
- WCAG 3.2.2 A: canceled saves no longer apply a response that closes preview; all-tenants selection is preserved through tested provider refreshes. Complete browser navigation, loading/status feedback (4.1.3 AA), visual focus quality and assistive-technology confirmation remain unverified. No product-level conformance claim is made.
