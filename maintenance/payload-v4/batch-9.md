## Request scoping and compatibility

An operation only creates a scoped request view when an explicit locale/fallback/depth differs from the incoming request. The locale, fallback, depth query slot and DataLoader belong to that view. Other query properties and transaction state retain their existing sharing behavior. The DataLoader closes over its request, so reusing the parent's loader would reintroduce cross-operation mutation even if the outer request properties were isolated.

Native Request getters and body methods require their original receiver. The proxy binds only unchanged native Request prototype methods, caches those bindings and preserves the constructor. Application methods remain unbound so they can see the scoped properties. Actual authenticated/anonymous GraphQL and REST POST regressions from earlier batches exercise this path as well.

Upload duplication keeps source file metadata as retrieval input; it does not trust an incoming business-field override as a different binary source. Normal upload generation still writes its generated identity. Neither access-control defaults nor file-integrity checks are bypassed.

## Reproduction

The first corrected seven-file focused baseline against the original production source had **15 failures and six passing controls** across 21 cases. These covered all six reports, including both SQL defects. Later controls add typed polymorphic IDs and native Request body/constructor/application-method behavior. Projection assertions normalize an absent or empty with object, since both correctly mean no related tables were fetched.

Restoring the original seven implementation files for the new SQLite suite produced **six failing integration tests**: both upload duplicate paths, both restored-version entity types, parent-only SQL projection and locale-preserving nested validation. All fixed sources were restored in a finally block before final verification.

The first combined integration run also exposed a native Request private-field error in two previous tests (GraphQL request parsing and a REST POST). A focused native-body test reproduced it. Binding the native methods to their original receiver corrected that regression; the combined suites then passed. This interaction was fixed before publication.
