- Four new component files run under a temporary local Vitest configuration using jsdom: **12 passed**. They remain in the repository's normal browser component discovery for CI. The temporary config changes no repository configuration, retries or timeouts.
- TypeScript builds for UI and translations, full package/tool lint, repository formatting (9,155 files), inventory arithmetic and whitespace checks passed. An intermediate new React immutability lint error was corrected by keeping request liveness in an effect-managed ref, then rerunning lint and the component regressions.

Browser components, real viewport/scroll behavior, native select keyboard interaction, full Admin upload notifications, production Next/TanStack rendering, HMR and assistive-technology verification remain pending. A jsdom pass is not a Chromium pass. No dependencies or workflow/quality gates are changed. Full CI must pass on the published revision before merge; this branch is not merged.
