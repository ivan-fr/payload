## Validation and evidence boundaries

The initial **12 browser cases all failed before the fixes**, one per report in both light and dark enhanced-contrast modes. After the fixes those same cases passed. The final suite adds ordinary-mode coverage: **24 passed** across six reports, light/dark themes and enhanced contrast on/off. CSS for shared tokens and the six affected components is read directly from production source, with no CSS overrides for the behavior being tested.

These are **isolated browser CSS contracts**, located in the canonical `test/a11y/e2e.spec.ts`. The fixtures reproduce the production selectors, host layout and the modal provider's competing unlayered rule. They run without a Payload server or database. They establish native browser cascade, geometry, internal scrolling, and the specific fixture interactions; they do **not** establish full Next.js/TanStack Admin integration, component/provider behavior, or accessibility conformance. Existing Admin workflow tests in the same file remain separate. No screenshot baseline, dependency, browser binary or fixture-only configuration is committed.

The normal Playwright Chromium download failed because its archive was truncated. For local validation only, Chromium **153.0.8010.0**, from the public `@sparticuz/chromium` npm package, was launched through the repository's existing Playwright. The browser and temporary Playwright config are outside the repository. CI uses its normal pinned browser setup. The six source styles pass targeted Stylelint; changed test code passes Oxlint with only pre-existing warnings elsewhere in that file. Oxfmt and `git diff --check` are checked before publication. No runtime TypeScript changes were made; a full app build, full unit suite and live database tests were not needed to validate this styles-only implementation and are not claimed run for this batch.

Reproduce with the existing E2E runner using `--grep 'Shared layout CSS regressions'`. The local isolated invocation was `pnpm exec playwright test --config /tmp/payload-batch29-playwright.config.ts`; that temporary config selects only these tests and the available local Chromium executable. Without an override, the repository's standard Playwright config selects these tests alongside the existing accessibility workflows.
